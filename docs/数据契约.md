# 原始资料契约

所有资料均为本地合成。JSONL一行一条来源观察，row_id仅标识该观察；同业务ID可以在不同revision、批次或接收位置出现。未写revision的静态目录按文件给定值解释，不隐含线上查询。事实字段中的None为缺少来源值，不是零或否。

金额字段以minor结尾时为该币种最小单位整数；数量、位置、时间的单位以字段后缀和政策说明为准。日期为ISO日期；绝对时刻携带偏移；原始received字段决定可见性，不能仅按发生日期提前使用资料。后续业务修改以相同格式输入，不限定样本编号。

## 业务政策

### feature

12维离线形态特征为合成数值，不包含答案族；None为缺失。split_group是母版隔离评估组，不得作为预测相似的特征。orientation和color是观察描述，主题/出处不是硬同源结论。 向量按次序分为3个4维形态块；provenance_statement是来源目录声明及确认状态，catalogued也不证明两资料同源；content_sha256是合成扫描字节身份声明，不能当作母版身份。

### holdout

holdout标签仅用于隔离评估，训练及选择方法不能使用，且同split_group不得跨训练与评估。候选分数及分族方法需公开解释并与简单近邻基准同样评估，不要求某预定模型或准确率。

### hard_reviews

同一review_id最高可见revision有效；withdrawn使该断言不再有效。same具有传递含义，different禁止同族。任一冲突的确认连通部分暂停作为确定可用族，保留涉及断言和对象版本，不能任意删除确认。新revision不继承旧版断言。 已确认labeled_pairs也构成其所引用版本的已知关系，但holdout关系只能在方法冻结后的独立评估及随后业务审阅中使用，不参与训练、调参或预测特征。首次处理可仅导入batch1，再接收后续批次。

### sampling

design只使用allowed_use且非in_review对象，并依据确定可用族执行每族上限；争议对象不可作为确定覆盖承诺。review可选争议对象但需标明，不允许重复分配已在审对象。接受计划须核对对象版次、约束断言及在审状态，族拆并引起变化需重新确认，不沿用旧覆盖数字。

## 资料检查

`python -m unittest discover -s tests -v`只检查资料字节与格式，不是尚未开发业务功能的验收。manifest.json中的摘要对应提交内原始字节，收到后续批次应独立登记来历，不修改旧原始记录。
